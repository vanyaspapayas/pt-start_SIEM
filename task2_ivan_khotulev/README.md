## Viewer

`viewer/index.html` — один файл, события выгрузки встроены в него, интернет не нужен.

- **Дерево процессов**: вредоносная ветка выделена красным.
- **Таймлайн**: клик по этапу оставляет в таблице только его события.
- **Таблица событий**: фильтры по процессу, PID, PPID, учётке, файлу или объекту, типу события и времени; флажок «только атака».

Пересобрать viewer из выгрузки:
```
cd viewer
python3 build_viewer.py Events.jsonl
```
Скрипт разбирает `body`, приводит PID к десятичному виду, сопоставляет переименованные типы событий с оригинальными (4688, Sysmon 1/3/11, 4656, 4663, 4690, PowerShell 4103) и размечает этапы атаки. HTML-шаблон лежит в `viewer/template.html`.
